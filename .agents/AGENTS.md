# Workspace Rules

- **Mandatory Startup Sequence**: Whenever you are invoked in this workspace for a new session or a major task, you MUST begin by reading the `docs/gemini.md` file (using the `view_file` tool). That file acts as the root configuration for this project and contains the execution directives and links to the full architectural and design system specifications. Do not start coding or planning until you have read and understood it and the related documentation it points to.
